SOLUSI PENYATUAN DOMAIN TUNGGAL

Bisakah Ketiga Aplikasi Dijadikan Satu Domain ke sicibinaga.my.id?

Sangat Bisa 100%! Meskipun sicibinaga7, sicibinaga8, dan sicibinaga9 berada di project Vercel dan database yang berbeda, Anda dapat menyatukannya di bawah satu domain resmi sicibinaga.my.id tanpa mengubah database maupun kode backend sedikit pun. Berikut 3 metode terbaik yang sudah disiapkan di dalam paket ZIP ini:

PALING DIREKOMENDASIKAN & BERSIH

Opsi 1: Satu Domain Utama dengan Vercel Reverse-Proxy Rewrites

Halaman Landing ini dipasang pada domain utama https://sicibinaga.my.id. File vercel.json yang sudah disertakan di dalam paket ZIP ini otomatis meneruskan (rewrite/proxy) rute ke masing-masing server Vercel tanpa mengubah URL di browser siswa:

  • https://sicibinaga.my.id → Halaman Landing Utama (Homepage)
  • https://sicibinaga.my.id/kelas7 → Meneruskan ke sicibinaga7.vercel.app
  • https://sicibinaga.my.id/kelas8 → Meneruskan ke sicibinaga8.vercel.app
  • https://sicibinaga.my.id/kelas9 → Meneruskan ke sicibinaga9.vercel.app
Cara Pasang di Vercel (Hanya 2 Menit):
  1. Upload folder/ZIP Landing Page ini sebagai project baru di Vercel (misal: sicibinaga-portal).
  2. Masuk ke menu Settings → Domains di project Vercel tersebut, lalu tambahkan domain sicibinaga.my.id.
  3. Arahkan DNS A Record (@) ke 76.76.21.21 dan CNAME (www) ke cname.vercel-dns.com di panel domain .my.id Anda. Selesai!
